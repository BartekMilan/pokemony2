# Placeholder assets for holo-card layers.

PNG assets can replace the solid-color fallbacks in the layer components:

- `background-fire.png` — Layer 0 elemental background
- `pokemon-charizard.png` — Layer 1 transparent Pokémon art
- `frame-overlay.png` — Layer 2 optional decorative frame PNG

Current implementation uses RN Views and emoji placeholders until assets are added.
